# Webvelop desktop application

The Electron application packaging the Webvelop editor (`../app`).

- `npm start`: run the desktop app with the development server of the editor (`cd ../app && npm start`).
- `npm run build -- --win --dir`: build the editor and package the desktop app in `dist/`.
- `npm run make-icons`: regenerate the icons of Webvelop.

All the data of the app is stored in the Webvelop data folder (see the main README).
